# ADR-001 — Local First

状态：Accepted（V0.1）
日期：2026-10-07

## 背景

测评对象是具体的人，回答是自陈材料。如果核心计算依赖我方服务器，就必须上传原始回答，随之而来的是数据留存、泄露面、跨境与合规问题，且离线不可用。

## 决策

核心业务全部在用户设备本地运行。断网状态下必须可以：打开应用、读取题库、生成问卷、答题、计算基础结果、查看结构化报告。只有 AI 自然语言报告需要网络，且是可选的。

## 后果

- 题库、评分模型、角色模型、Prompt 全部作为构建产物随应用下发（见 ADR-005、`src/content/load-content.ts`）。
- 第一阶段评分引擎是纯函数，不进行任何 IO（`src/engine/scoring.ts`，`tests/unit/scoring.test.ts`）。
- 会话对象自带 `questionIds` 与 seed，历史结果不依赖服务端状态（Engineering Bible §12）。
- 代价：无法做跨设备同步、无法集中分析回答分布。V0.1 明确接受这个代价（§67）。
- 若公开部署到 GitHub Pages，前端题库与评分规则无法保密（源 README 第 85 行）。这属于部署决策，不属于本 ADR 的变更范围。
