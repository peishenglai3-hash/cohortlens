# ADR-019 — A 层呈现政策：六部分分别呈现，且永远不可合计

状态：Accepted（A-layer V1.1）
日期：2026-10-08
关联：ADR-018（A 层 V1.1 配额）、ADR-014（报告载荷白名单）

## 背景

V1.0 的 A 层是四个分数行，"不生成单一总分""不得解释为政治立场"这套边界靠的是**不显示**：维度名
是中性的（概念理解、理论与现实、组织判断），选项分值是 0–3。产品可以说"理论层只描述概念理解"。

V1.1 把 A 层换成六部分之后，这个说法**不再成立**：

- A0 是答题者直接自报的政治—理论身份类别（受控词表，例如 `stable_open`、`public_explicit`）。
- A1 是有正确答案的概念题，12 题 4 个选项位置各 3 次。
- A2/A3 是答题者在政治经济与社会—政治议题上**自己选出的立场**。
- A4 是实践取向，A5 是反身性。
- A2–A5 的选项带 `profileSignals`（35 条轴，取值 −2…2），供探索性校准用。

于是出现三个真实风险，都不是靠"提醒一下"能挡住的：

1. **把自报当测量。** 一旦 A0 有归一化分数，界面与导出就会把它读成"政治意识得分"，而它其实只是
   答题者的自我描述。规范要求 A0 只能来自直接自报，不得从 A1–A5 推断。
2. **把六部分加起来。** 六个分数行天然诱导求和；一个"政治—理论总分"正是产品边界明令禁止的东西。
3. **把稀疏样本压成精确结论。** A1 单次只有 3 题；A2–A5 单次只有 2–3 题。`a-scoring-model-v1.1`
   自己写明探索性信号 `userFacingByDefault: false`，并要求 A2–A4 用"证据卡"而不是伪精确轴分数。

## 决策

**1. A 层结果在结构上不可能合计。** `ALayerProfile` 里没有任何字段能装下一个 A 层总分，
`scoring.layerA.aggregateTotalScore` 必须为 `false`，校验器 `a_layer_scoring_policy_consistency`
逐条核对：六维都有 `displayPolicy`、探索性信号不面向用户、`useInRoleFit` 与
`useForAdmissionDecision` 均为 false。测试再从**序列化结果**里搜 `aTotal` / `aLayerTotal` /
`politicalFit` / `ideologyScore`，确认没有偷偷多出一个字段。

**2. 无分维度不再伪造成 0 分。** 新增 `DimensionResult.scoringKind`
（`numeric` / `knowledge` / `categorical` / `descriptive`）与 `scoredItems`。
`scoredItems === 0` 的维度：`band` 为"不产生分数"、进度条不渲染、界面显示"不产生分数"徽标而不是
`0`，导出文本写"不产生分数（本次作答 N 题）"，AI 载荷带上 `scoringKind` 与 `scoredItems`。

> 这一条是本次改动里最容易被低估的：`0` 与"没有这个数"在读者眼里是同一件事，而前者会被读成
> "这方面很差"。

**3. 六个维度各自的呈现形态写进内容，不写死在界面里。**
`scoring-v1.1.layerAProfilePolicy.displayPolicy` 逐维声明，独立文件
`content/scoring/v1/a-scoring-model-v1.1.json` 与 `a-result-schema-v1.1.json` 一并装载并校验。
界面按 `displayPolicy` 渲染，因此换一版 A 层政策不需要改组件。

**4. 界面重构为六张分区卡**（`src/pages/Result/ALayerSection.tsx`）：

| 卡片 | 呈现 | 明确不呈现 |
| --- | --- | --- |
| A0 自我声明的理论认同 | 引用答题者选中的选项原文 + 自报类别 | 任何数字、进度条、"得分"字样 |
| A1 理论熟悉程度 | 答对/作答 + 0–100 + 低精度提示 | 理论水平、学术能力的措辞 |
| A2/A3 议题立场 | 题干 + 本人选择（证据卡） | 折算分数、轴分数 |
| A4 实践取向 | 同上 | 同上 |
| A5 反身性 | `aligned` / `mixed` / `insufficient` 状态 + 谨慎摘要 | 状态不是 aligned 时的结论 |

A5 的摘要只在两道题方向一致时才给出低置信度倾向；方向不一致写"mixed"，材料不足写
"insufficient"，两者都不替答题者总结。

**5. 排序类输出排除无分维度。** "主要优势/可能需要更多信息的方向"只从
`scoredItems > 0` 的维度里选，且 A1 用 knowledge 专用措辞（"答对 X 题，低精度提示"）。
把 A0 列成优势或短板，等于把自我描述变成对人的评价。

**6. AI 载荷分开处理，并撤回一句不再准确的话。**
prompt v1 的约束 5 是"不把理论层解释为政治立场"——在 V1.1 下这句话**是错的**：A2/A3 确实承载
答题者自报的议题立场。继续沿用会造成两种相反的错误（把真实存在的自报立场说成与政治无关，
或把六部分合成一个政治倾向结论）。prompt 升级为 **v2**：

- 输出结构新增 `## A 层画像的呈现方式`；
- A0/A1/A2–A4/A5 各一条独立规则，其中 A2–A4 **载荷里没有选项原文**（只有题量与主题标签），
  因此模型被明确禁止描述、猜测或复述其具体立场；
- 新增"六部分不得相加"与"A 层不得用于角色适配/吸纳/淘汰"两条硬约束。

载荷新增 `aLayer` 字段，仍走 ADR-014 的白名单：A0 只带受控类别名，A2–A4 只带 `itemCount` /
`topics` / `questionIds`。**选项原文属于答卷内容，按 §60 不进载荷**；卡片上的立场只给答题者本人看。

## 后果

- 新增 40 条 A 层单元测试（`tests/unit/a-layer-v11.test.ts`）与 2 条 E2E，分别钉住配额、
  A0 无分数、A 层不进 role-fit、旧映射已移除、A1 位置均衡、选项顺序不被破坏、跨版本拒绝、
  载荷不含选项原文、界面不把 A 层渲染成分数行。
- `renderResultText`（打印/PDF 用的纯文本）同步重构，A 层输出六个叙事小节而不是 `/ 100` 行。
- 载荷带 `scoringKind` 后，模型不会把 `score: 0` 读成"得分很低"；这是上一版载荷里没有的信息。
- 校验器新增六项 A 层检查（配额形状、A0 只自报、A1 位置均衡、选项顺序策略、旧一致性组已移除、
  A 层呈现政策自洽），并且 A 层措辞扫描在 60 题上零命中。
- 代价：`report-prompt-v1` 的 md 镜像保留为历史，现行镜像为
  `content/prompts/report/v2.md`；两者都在文件头标明哪一份是执行版本。
