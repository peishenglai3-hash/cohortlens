# ADR-002 — V0.1 没有后端

状态：Accepted（V0.1）
日期：2026-10-07

## 背景

工程圣经第 1 节列出 V0.1 不建设：账号系统、我方云端数据库、中心服务器、多人协同后台、远程题库同步、支付、权限中心、组织 SaaS。

## 决策

构建输出必须是纯静态文件（`npm run build` → `dist/`），可直接放到 GitHub Pages、任意静态文件服务器或本地 HTTP Server 上运行，不需要 Node 进程常驻。

## 后果

- 路由采用 **hash router**。深链接无需服务端 rewrite，静态托管零配置即可工作；代价是 URL 带 `#`。对一个小型本地优先工具，可用性优先于 URL 美观。
- 没有服务端就无法做：远程问卷派发、二维码群体收集、在线排行榜、云端分析。全部进入 Backlog（§67）。
- 无服务端也意味着没有服务端密钥，因此"Key 不得进入仓库"的约束只剩一个入口：用户自己的浏览器（见 ADR-004）。
- `content/` 与 `src/` 的分离让"换题库/换角色/换 Prompt 即换一套系统"成为 fork 的操作而不是重构（§63）。
