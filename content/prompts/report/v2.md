# 报告 Prompt v2 — 人类可读镜像

版本标识：`report-prompt-v2`
实现：`src/infrastructure/ai/prompts/report-prompt.ts`（**代码侧为唯一执行版本**）
用途：给人类审阅与修改用。改这个文件不会自动改变运行行为；要改行为请同步改 TS 常量。

> 为什么用 TS 常量而不是构建时读取这个 md：报告 Prompt 必须能在无网络、无 fetch、无插件配置的情况下工作（Local First）。用构建时读取会引入一个新的失败点，而收益只是"不用改代码"。这里选择把执行版本放在代码里，把这份 md 作为可读镜像，并在两边各自标注版本号。

## v2 相对 v1 的变化

A 层从 V1.0 的四维分数换成 V1.1 的六部分画像后，v1 的第 5 条约束（"不把理论层解释为政治立场"）已经**不准确**：A2/A3 现在确实承载答题者自报的议题立场。继续沿用会造成两种错误——要么模型把真实存在的自报立场说成"与政治无关"，要么模型把六部分合成一个政治倾向结论。

v2 因此把 A 层拆成六条独立规则，并新增一节输出结构：

- 输出结构新增 `## A 层画像的呈现方式`（位于"主要优势"之后）。
- 第 5 条展开为 A0/A1/A2–A4/A5 四条分别的规则。
- 第 6 条明确禁止任何跨部分合并（总分、立场指数、政治倾向评分）。
- 第 7 条明确禁止把 A 层用于角色适配、吸纳或淘汰。
- 载荷新增 `aLayer`（见下）。

## 输出结构（必须严格遵守，顺序固定）

1. `## 整体概况`
2. `## 主要优势`
3. `## A 层画像的呈现方式`
4. `## 合作方式`
5. `## 任务风格`
6. `## 适合承担的工作类型`
7. `## 可能的磨合点`
8. `## 建议进一步人工了解的问题`
9. `## 测评局限性`

## 硬性约束（违反任何一条即为不合格输出）

1. 不重新打分。所有分数都已由本地引擎算好，只能引用，不能修改、加权、相加或重新归一化。
2. 不产生任何总分、综合分、排名、等级或百分位。
3. 不判断这个人是"谁"。只描述"当前这份问卷的回答呈现出什么"。
4. 不输出：录用、淘汰、通过、不通过、政治可靠、政治不可靠、忠诚、意识形态纯度、值得信任、不值得信任、危险人物、撒谎概率、欺骗指数、真实性评分。
5. A 层六种输出形态分别对待：
   - **A0 自我声明的理论认同**：只能引用 `declaredIdentity` 里的类别名称，不得从 A1–A5 或其他维度推断、补全或改写；不得评价类别好坏。
   - **A1 理论熟悉程度**：仅 2–3 道概念题，`lowSample` 恒为 true。必须写明题量极少；不得说成理论水平、学术能力或政治资格。
   - **A2/A3/A4 证据卡**：载荷只给题量与主题标签，**不给**答题者的具体选项。因此不得描述、猜测或复述其在这些议题上的具体立场。
   - **A5 反身性**：带明确 `state`（aligned / mixed / insufficient）。非 aligned 时必须如实写"方向不一致"或"材料不足"，不得代为总结。
6. A 层六部分不得相加成任何"政治—理论总分"、立场指数或政治倾向评分。任何跨部分合并都是不合格输出。
7. A 层不得用于角色适配、吸纳或淘汰判断，也不得暗示"因为 A 层是这样，所以他适合/不适合"。
8. 不做心理诊断，不推测精神健康状况，不推测家庭、健康、性取向、宗教、民族等未提供的信息。
9. 不用单个答案下强结论。某维度只有 1–2 题支撑或置信度偏低时，必须明确说明材料不足。
10. 不推测结构化结果里没有的信息。缺什么就说缺什么。
11. 引用证据时只使用给出的 question id，不编造题目内容，不编造答题者选了什么。

## 输入载荷

由 `buildReportPayload` 白名单构造（ADR-014）。进入载荷的字段：

- `promptVersion`、`versions`（题库 / 评分 / 角色模型 / 题库语言）
- `dimensions[]`：`id`、`label`、`layer`、`score`、`band`、`items`、`confidence`、`evidenceQuestionIds`、`scoringKind`、`scoredItems`
- `aLayer`（A 层 V1.1 新增）：
  - `displayPolicy`：每个 A 维度允许以什么形态呈现
  - `declaredIdentity[]`：`questionId`、`topic`、`selectedCategory`（**只有受控类别名，没有选项原文**）
  - `theoryFamiliarity`：`correct`、`answered`、`normalizedScore`、`band`、`lowSample`
  - `measuredItems[]`：A2–A4 的 `dimension`、`itemCount`、`topics`、`questionIds`（**没有 `selectedText`**）
  - `reflexivity`：`state`、`confidence`、`evidenceQuestionIds`
  - `boundaries[]`：A 层自述边界，与结果页展示的一致
- `roleFits[]`：`roleId`、`name`、`fitScore`、`coverage`
- `strengths[]`、`developmentAreas[]`、`consistency`、`limitations[]`、`boundaries[]`

**不进入载荷**：A2–A5 的作答原文与所选选项 id、B/C 层作答原文、session id、result id、任何身份字段、任何 API Key。

- `scoringKind` / `scoredItems` 的作用：让模型区分"真的得了 0 分"和"这一部分不产生分数"。A0 与 A2–A5 的 `score` 字段恒为 0，若模型不知道 `scoringKind`，最自然的误读就是把自报材料写成"得分很低"。

## 输出后的处理

模型返回的文本在显示与落盘之前先过 `maskForbiddenLanguage`。命中禁用词即替换为 `[已按产品边界屏蔽]`，并把命中词记入 `ReportRecord.sanitizedViolations`，在报告顶部告知用户。

渲染使用自写的小型 Markdown 渲染器（标题 / 列表 / 引用 / 段落），全流程无 `dangerouslySetInnerHTML`。
